## 🛠️ Local Installation & Development

To run this portfolio locally on your machine:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Pramod3570955/portfolio.git
   cd portfolio
   ```

2. **Run a Local HTTP Server**:
   ```bash
   # Using Python 3
   python -m http.server 3000

   # Or using Node.js / npx
   npx serve
   ```

3. **View in Browser**:
   Open [http://localhost:3000](http://localhost:3000) or double-click `index.html` to view.
